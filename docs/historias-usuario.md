# Historias de usuario

## Cliente

### Iniciar sesión

Como cliente, quiero iniciar sesión con mi rol, para acceder a la vista de cliente.

### Consultar servicios y disponibilidad

Como cliente, quiero ver los servicios y la disponibilidad de horarios, para elegir un turno.

### Reservar turno

Como cliente, quiero reservar un turno eligiendo horario y servicio, para confirmar mi reserva.

### Cancelar turno propio

Como cliente, quiero cancelar un turno mío, para liberar ese horario cuando corresponda.

### Consultar al agente de IA

Como cliente, quiero preguntarle al agente de IA por horarios, servicios o reglas, para obtener esa información sin confirmar un turno por mi cuenta.

## Administrador

### Iniciar sesión

Como administrador, quiero iniciar sesión con mi rol, para acceder a la vista de administrador.

### Ver la agenda del día

Como administrador, quiero ver toda la agenda del día, para conocer los turnos de esa jornada.

### Adelantar o ajustar el reloj simulado

Como administrador, quiero adelantar o modificar la fecha y la hora del reloj simulado, para probar el sistema.

### Revisar la bandeja de correos simulados

Como administrador, quiero revisar la bandeja de correos simulados, para ver las notificaciones internas de confirmación y cancelación.
